# Фоновые workers Gateway

Gateway запускает обслуживающие процессы независимо. Медленная внешняя проверка или очистка одной категории не задерживает восстановление генераций, аренды майнинга и остальные workers.

## Контракт выполнения

- У каждого worker есть собственные interval, timeout, initial delay и bounded exponential backoff.
- Один key не запускается повторно, пока предыдущий запуск не завершён.
- Ошибка сохраняется в реестре конкретного worker и не останавливает соседние процессы.
- Успешный запуск сбрасывает счётчик последовательных ошибок.
- При завершении Gateway общий context отменяется, сервер ждёт остановки всех циклов в пределах shutdown timeout.
- Недоступность отдельной зависимости отражается в dependency health. Ошибка самого обслуживающего вызова дополнительно видна в строке worker.

## Реестр

Системная страница администратора показывает для каждого процесса:

- состояние: ожидает, выполняется, работает, повтор после ошибки или остановлен;
- последний запуск и последний успешный запуск;
- длительность и количество обработанных записей;
- следующую попытку и число последовательных ошибок;
- последнюю техническую ошибку.

Текущее состояние процессов находится в памяти Gateway. Постоянные снимки очереди, backlog, размера БД и cleanup, а также сквозной correlation ID сохраняются отдельно и доступны на странице наблюдаемости.

## Процессы

| Key | Назначение | Обычный интервал | Timeout |
| --- | --- | ---: | ---: |
| `generation_jobs` | Восстановление и согласование durable jobs с ComfyUI | 30 сек. | 20 сек. |
| `mining_leases` | Восстановление старых leases вне job lifecycle | 30 сек. | 15 сек. |
| `host_metrics` | Получение и сохранение метрик Windows | 30 сек. | 8 сек. |
| `observability_snapshot` | Сохранение очереди, backlog, leases, размера БД и состояния cleanup | 30 сек. | 8 сек. |
| `comfy_memory` | Наблюдение перехода очереди ComfyUI в idle | 10 сек. | 8 сек. |
| `dependency_health` | Проверка всех зависимостей Gateway | `DEPENDENCY_CHECK_INTERVAL` | 4 сек. |
| `websocket_authorization` | Закрытие соединений с истёкшими сессиями | 1 мин. | 8 сек. |
| `suggestion_scans` | Обновление существующей очереди VirusTotal | 15 мин. | 2 мин. |
| `media_archive` | Архивация ещё не сохранённых результатов ComfyUI | 15 мин. | 2 мин. |
| `media_hashes` | Backfill хэшей зашифрованных медиа | 15 мин. | 2 мин. |
| `comfy_input_cleanup` | Удаление истёкших входных референсов | 15 мин. | 3 мин. |
| `comfy_media_cleanup` | Удаление истёкших результатов ComfyUI | 15 мин. | 3 мин. |
| `other_media_cleanup` | Удаление истёкших медиа других сервисов | 15 мин. | 15 сек. |
| `database_retention` | Пакетная очистка технических таблиц | 15 мин. | 2 мин. |
| `session_cleanup` | Удаление истёкших сессий | 15 мин. | 15 сек. |
| `temporary_users` | Полное удаление истёкших временных аккаунтов | 15 мин. | 15 сек. |
| `content_cleanup` | Удаление истёкших событий AI-контента | 15 мин. | 15 сек. |

Gateway не запускает, не останавливает и не обновляет пользовательский процесс ComfyUI. Worker `comfy_memory` только наблюдает очередь и использует уже существующий явный путь освобождения памяти через настроенный Windows-agent.
