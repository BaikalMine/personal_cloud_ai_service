# F02: сохраняемый редактор датасетов

Продолжение [серверного этапа](LORA_DATASET_BACKEND_2026-09-05.md).
Изменения проверяются локально. Production и пользовательский ComfyUI не
перезапускались; реального обучения или обращения к GPU не было.

## Реализовано

- Редактор использует серверный набор вместо временного списка File на странице.
  Сохраняются фотографии, точные ручные подписи, порядок, исключения, триггер,
  концепт, профиль, пресет и рабочее разрешение.
- Выбор существующего набора, создание нового, явное сохранение/повтор запроса,
  удаление с подтверждением. Автосохранение сериализовано и сохраняет правки,
  сделанные во время предыдущего HTTP-запроса.
- Сбой начальной загрузки блокирует поля до повторного чтения. Конфликт вкладок
  оставляет локальные правки и предлагает загрузить серверную версию или
  сохранить отдельную копию. Создание повторяется с тем же client_id после
  потерянного ответа, не расходуя вторую квоту набора.
- Загрузка файлов с устройства выполняется по одному. Незагруженные фотографии
  остаются на странице для повторной попытки и явно мешают считать набор
  полностью сохранённым. Закрытие с несохранёнными правками вызывает стандартное
  предупреждение браузера.
- Выбор собственных фотографий из AI-контента, без промежуточного скачивания.
  API доступен обладателям права обучения, независимо от права быстрой генерации.
  Существующая логика скрытия чувствительных миниатюр сохранена.
- Версии: создание, просмотр своего/всех наборов, скачивание ZIP, удаление и
  восстановление в новый рабочий набор. На экране есть срок хранения.
- ZIP: изображения и отдельные UTF-8 txt-файлы плюс переносимый dataset.json.
  Экспорт сохраняет также исключённые кадры. Поддерживается обычный ZIP с
  изображениями и одноимёнными txt без manifest, порядок по имени файла.
- Импорт проверяет пути, размер, число записей, UTF-8 подписей, содержимое фото
  и ревизию. Неудачный импорт не заменяет manifest. Новые orphan assets после
  частично обработанного ZIP подлежат действующей 24-часовой очистке.
- Создание ZIP на диске и материализация по одному фото; скачивание не держит
  весь архив в JS Blob. Временные файлы удаляются после запроса и при ошибках.
- Помощник подписей по-прежнему отправляет одно изображение за запрос. Поздний
  ответ не заменяет изменённую вручную подпись или подпись с изменённым триггером.
- Обучение отправляется через versioned endpoint, а новая запись сразу появляется
  в истории. Старый multipart endpoint сохранён для совместимости.
- Вместо старого редактора на 440 строк подключены отдельные controller и DOM
  adapter; lora-training.js теперь отвечает только за историю заданий.

## Проверки

- Все Go-пакеты: `go test ./...`, успешно.
- PostgreSQL 16 в отдельном tmpfs контейнере: миграции, store, gateway с
  `-p 1 -count=1`, успешно, без пропуска DB-тестов.
- Добавлены HTTP-проверки повторного create, экспорт/импорт ZIP, точных подписей,
  исключений, generic ZIP, повреждённых архивов/фото, CAS, восстановления версии
  после удаления рабочего набора и отсутствия утечек временных файлов.
- JS: 58 успешных тестов, включая семь новых тестов controller.
- Фокусный браузерный прогон: 12 успешных, 24 предусмотренных пропуска повторов
  desktop-only сценариев. Набор из 100 фото закрыт и повторно открыт в новой
  странице, первая и последняя ручные подписи сохранены; 101-й кадр отклонён.
- Другие браузерные сценарии: 5 кадров и запуск через fixture, reorder/exclude,
  версии и восстановление копии, ZIP, галерея, две вкладки, поздний ответ
  ассистента, повтор после ошибки загрузки.
- Визуально просмотрены редактор и диалоги на 390/768/1440/1920. Проверены
  переполнение, загрузка реальных локальных JPG, Escape и возврат фокуса;
  axe не нашёл serious/critical ошибок в проверенном диалоге галереи.
- Изменены только четыре ожидаемых эталона пользовательской страницы обучения.
  Административная страница обучения эталоны не изменила.
- Полный Playwright gate без обновления эталонов: 79 успешных, 69 штатных
  пропусков desktop-only повторов, 0 ошибок, 4,7 минуты. Проверены также
  генерация Krea2/Flux2/MiniMax, черновики, контент, пользователи и остальные
  действующие поверхности, включая общую axe-проверку.
- Одноразовая PostgreSQL удалена после проверок. Собственный UI-preview оставлен
  доступным; чужие контейнеры, production и ComfyUI не менялись.

Артефакты: `artifacts/playwright/f02-final-editor/` и
`artifacts/playwright/f02-full-gate/`. Они локальные, не входят в Git.
Preview: `http://127.0.0.1:18085/preview/lora-training`, только тестовые данные.
