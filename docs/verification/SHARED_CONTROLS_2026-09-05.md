# D02: общие поля и элементы управления

## Объём

Общие поля, кнопки, бинарные переключатели, сегменты и раскрываемые настройки
имеют одного владельца в `controls.css`. Он подключён к общему layout и входит
в fingerprint статических файлов. Старые базовые определения и конфликтующие
правила высоты/выравнивания удалены из `style.css`.

В формах генерации Krea2, Flux2, MiniMax, обучения LoRA, пользователей,
приглашений, профиля, авторизации, галереи, предложений и майнинга отделены
подписи от controls. Группы полей используют общие строки subgrid для подписи,
контрола и сообщения. Длинный label или ошибка не сдвигают соседнее поле.
Количество колонок остаётся ответственностью страницы. Для браузеров без
subgrid предусмотрен независимый grid без потери содержимого.

Подписи используют 13 px/600, значения 14 px/500, пояснения 12 px/400.
На узких экранах значения увеличиваются до 16 px. Обычный control имеет высоту
44 px. Checkbox остаётся нативным, 18 px внутри более крупной области нажатия.
Заголовки страницы/раздела приведены к токенам 26/18 px.

Опциональные модули MiniMax используют общую строку переключателя. Включение
модуля больше не меняет внутреннюю ширину из-за дополнительной левой рамки.
Номера строк LoRA выровнены по самому select, а не по подписи.
Раздел точных настроек использует native details с общей индикацией открытия.

## Сохранность функциональности

Миграция шаблонов выполнялась по позициям узлов HTML-парсера без повторной
сериализации Go templates. Одноразовое сравнение с исходным commit `5a92669`
подтвердило точное совпадение исходных открывающих тегов 799 элементов
`input`, `select`, `textarea` и `option` во всех затронутых продуктовых шаблонах.
Демонстрационный component preview исключён из этого сравнения.

Имена полей, значения, ограничения, доступные опции, состояние optional-модулей,
данные repeat, права и payload генерации этим этапом не менялись. HTML-парсер
использовался только как локальный инструмент миграции; зависимости приложения
и package manifests не менялись.

## Проверки

- `go test -p 1 ./... -count=1`: все пакеты прошли. В этом прогоне не задан
  `TEST_DATABASE_URL`, поэтому проверки с PostgreSQL не выполнялись. Код БД
  в данном этапе не менялся.
- Node: 74/74, включая новый guard единого владельца controls и проверку
  подключения stylesheet к общему layout.
- Начальный Playwright-прогон: 14/14 на 390 и 1440 px, обе темы. Проверены
  перенос label, длинная ошибка, keyboard, disabled/readonly, Krea2 text/edit,
  Flux2 edit, MiniMax frames/references и формы LoRA/приглашений/пользователя.
- После визуального просмотра исправлено положение номера LoRA; добавлено
  измерение его центра относительно select.
- Первый полный UI gate: 165 успешных, 101 штатный пропуск и 10 ошибок на
  768 px. Все ошибки сводились к двум дефектам: фиксированным минимальным
  колонкам профиля качества и сжатию LUT-переключателя. Профили теперь
  переходят на отдельную строку до того, как им становится тесно; LUT использует
  устойчивую сетку и общие поля. Его быстрые пресеты имеют высоту 44 px.
- После исправления `controls-reflow`: 37 успешных, три штатных пропуска,
  ошибок нет. На четырёх viewport проверены обе темы, все пять сценариев,
  включая включённый LUT в Krea2/Flux2, и затронутые снимки генерации.
- Общий gate `controls-acceptance` с read-only репозиторием и без обновления
  эталонов: 172 успешных, 101 штатный пропуск и три расхождения снимка PhotoFlow
  на 390/768/1440 px. Проверки логики, overflow и доступности прошли. После
  переноса профилей изменилась субпиксельная позиция длинного блока; снимки
  просмотрены, включая diff. Порог сравнения не ослаблялся, элементы не скрывались.
- Адресное обновление трёх эталонов: четыре успешных проверки на всех viewport.
  Затем `controls-photoflow-check` с read-only репозиторием, без обновления
  эталонов и с `--repeat-each=2`: 8/8, без ошибок. Между общим gate и этим
  повтором код приложения и тестов не менялся. Полный набор целиком после
  обновления этих трёх PNG не повторялся.
- После последней правки LUT все Go-пакеты и 74 JS-теста повторно прошли.

Артефакты: `artifacts/playwright/controls-check`, `controls-regression`,
`controls-diagnose`, `controls-reflow`, `controls-acceptance`,
`controls-photoflow-baseline`, `controls-photoflow-check`.
Визуально просмотрены MiniMax на desktop/mobile, Krea2 в светлой теме,
тёмная мобильная матрица состояний, административные формы, исправленные
профили качества и включённый LUT на планшете, PhotoFlow со всеми раскрытыми
модулями. Временный каталог HTML-парсера и скрипты миграции удалены после
проверки; в репозиторий они не входят.

## Границы

Это общий слой компонентов D02, а не новая информационная структура студии
D03. Трёхшаговый рабочий путь пока сохранён. Другие компоненты, переработка
страниц D03-D09, браузерная приёмка и rollout остаются открыты.

Production, ComfyUI, майнинг и Docker Desktop не перезапускались. Обновлялся
только собственный изолированный UI preview. Генерации/обучение на GPU не
запускались, security-функциональность не менялась.
