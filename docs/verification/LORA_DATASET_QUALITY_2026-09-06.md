# F02: рекомендации качества датасета

## Что изменено

- В редакторе добавлена отдельная команда «Проверить качество». Она не вызывает
  модель, не использует GPU и проверяет сохранённые включённые фото по одному.
- Для нерезкости показывается осторожная рекомендация проверить полный кадр:
  измерение находит недостаток мелких деталей, а не устанавливает причину.
- Для похожести сравниваются цвета и композиция уменьшенных изображений с
  близкими пропорциями. Подсказка ссылается на текущий номер предыдущего кадра.
- Для разнообразия фона используются только цвета граничных ячеек. Сообщение
  прямо предлагает проверить фон, не утверждая, что он распознан нейросетью.
- Точные дубликаты не увеличивают число голосов за одинаковый фон. Исключённые
  кадры не участвуют в рекомендациях. Перестановка/исключение пересчитывает
  сообщения без чтения исходных изображений.
- Рекомендации отделены от состояния ассистента подписей. Ни подписи, ни trigger,
  ни флажки включения не меняются. Обучение не блокируется рекомендациями.
- Есть прогресс по числу фото, остановка, понятный отказ и повтор только для
  непроверенных кадров. Поздний ответ старого набора не применяется к новому.

## Сохранение и ресурсы

Миграция 66 добавляет `lora_dataset_assets.quality_cipher`, максимум 4096 байт.
В нём тем же content cipher сохраняются версия алгоритма, числовая оценка
деталей и 192 усреднённых цветовых значения. AAD привязан к asset ID и hash.
Это производные данные, не дополнительный файл фото и не кеш модели.
Они удаляются вместе с исходным asset и попадают в обычный PostgreSQL backup.

GET набора восстанавливает готовое состояние без декодирования фото и без
повторных POST. Неизвестная версия или повреждённые измерения считаются
непроверенными; оригинал остаётся доступным, пользователь может повторить анализ.
Измерения не входят в manifest и не меняют revision, snapshot или обучение.

POST `/api/lora-datasets/assets/{id}/quality` проверяет владельца и существующий
CSRF-контракт. При готовом результате читает только метаданные. Для первого
расчёта материализуется один файл с проверкой hash/AEAD, используется общий лимит
памяти, проверяются размеры и целостность изображения. При отказе или отмене
освобождаются резервирование памяти и временный файл. Новых GPU-процессов нет.

## Границы измерений

Версия 1: превью с длинной стороной до 256 px; дисперсия дискретного лапласиана
яркости ниже 12 вызывает подсказку о деталях. Прозрачность компонуется на белом.
Средние RGB по сетке 8×8 сравниваются по среднему абсолютному отклонению:
меньше 6 для похожей композиции при разнице log-пропорций меньше 0.08;
меньше 10 для цветов по краям. Для общей подсказки о фоне нужны минимум три
разных hash и группа не менее 70% проверенных уникальных кадров.

Это простые эвристики, не оценка пригодности LoRA и не семантическое сравнение
лиц/предметов. Мягкий свет, однотонные фоны, художественное размытие и некоторые
текстуры могут дать ложные подсказки. Отсутствие подсказок не гарантирует качество;
интерфейс явно это сообщает. Изменение измерений требует новой версии алгоритма.
Проверка на размеченном реальном корпусе не заявляется; F06 остаётся отдельным
пунктом плана, а D07 ещё включает переработку всего экрана и паспорт LoRA.

## Проверки

- Полный `go test -p 1 ./... -count=1` с отдельной PostgreSQL: успешно.
- Синтетические изображения: однотонные, резкие, гладкие, прозрачные, смещённые
  bounds и экстремальные пропорции. Проверена конечность метрик и сравнение деталей.
- HTTP/БД: сохранение и чтение измерений, отсутствие plaintext, чужой владелец,
  CSRF, неверный метод, повтор без декодирования, повреждённый результат,
  отказ по памяти, отмена, отсутствие утечек spool и памяти. Действующие тесты
  неизменяемых snapshots, captions, ZIP и сохранения датасета продолжают проходить.
- JS: 110 успешных тестов, включая семь новых для рекомендаций, последовательной
  проверки, повторов, отмены, смены набора, hash и восстановления сохранённого состояния.
- Регрессия редактора и панели подписей: 51 успешная, 33 штатных пропуска
  desktop-only повторов; 100 фото, reload, версии, ZIP, галерея и конфликты вкладок.
- После добавления хранения измерений повторены новые UI-сценарии: 10 успешных,
  6 штатных пропусков. Светлая/тёмная темы, 390/768/1440/1920, отмена и 429,
  реальные CPU-измерения в preview, reload без новых запросов. Проверки overflow
  и axe для блока датасета прошли; снимки карточки и действий просмотрены.
- `go vet` затронутых пакетов, `git diff --check`: успешно.

Первый полный Go-прогон обнаружил незарегистрированный production-маршрут нового
JS-файла. Регистрация исправлена, последующие полные прогоны прошли.
Preview не используется как единственное доказательство production-подключения.

Артефакты локальные: `artifacts/playwright/f02-quality-final/` и
`artifacts/playwright/f02-quality-persisted/`. Preview с тестовыми данными:
