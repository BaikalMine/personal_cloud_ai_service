# Восстановление панели промпт-ассистента

## Изменение

Панель генерации подключена к постоянным заданиям через существующий
`PROMPT_ASSISTANT_DURABLE_JOBS`. По умолчанию переключатель остаётся выключен;
старый синхронный маршрут сохранён. Production в этом этапе не обновлялся.

- ID сохраняется в браузере до POST. Потеря ответа вызывает только GET того же
  задания, а не повторный запуск модели. Повторные проверки имеют реальный отсчёт.
- Черновик на сервере сохраняет ID задания и факт ручного редактирования варианта.
  После загрузки черновика панель восстанавливает проверку состояния.
- Сравнение контекста использует сохранённые идентификаторы материалов вместо
  временных blob URL. В контекст входят модель, режим, инструкции и роли референсов.
- Уход со страницы прекращает только клиентский опрос; возврат через back/forward
  восстанавливает его. Явная отмена является отдельным серверным действием.
- Поздний ответ не меняет текущий промт, ручной вариант и фокус закрытой панели.
  Несовпадающий ответ доступен отдельно для чтения; применение требует проверки.
- Отмена неизвестного ещё POST резервирует его ID под блокировкой GPU-ресурса.
  Запоздавшая отправка не принимается. Подтверждение отмены доступно владельцу
  через GET после перезагрузки в течение суток; чужие и истёкшие записи скрыты.
- Отмена до получения ответа не освобождает GPU реально работающего исполнителя.

## Остаток

Это не закрывает F04. Ещё нужны подтверждение состояния модели после потери
inference-исполнителя, смешанная нагрузка, реальные GPU-сценарии и согласованный
выпуск. Панель восстанавливает один текущий запрос; общий список всех видов
задач относится к F07/D06. При конфликте серверного черновика с другим активным
локальным заданием его ID не заменяется автоматически. Полная матрица прав,
Firefox/WebKit и release smoke остаются в общей приёмке.
